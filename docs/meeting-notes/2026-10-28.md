### 안건 2. 아이디어 후보

| 후보 | 한 줄 소개 | 논의된 장점 | 논의된 고민점 |
|---|---|---|---|
| **EcoFit (확정)** | 전기차 운행 데이터로 전기를 덜 쓰는 운전 습관을 알려주고 예상 금액까지 보여주는 앱 | 매 주행 반복 사용, 차량 데이터(배터리·브레이크·속도) 필수 | - |
| 경고등 통역사 | 차량 경고등의 의미와 필요한 조치를 쉬운 말로 설명하고, 필요하면 가까운 정비소로 안내 | 문제 상황이 분명함 | 경고 API가 실제로 어떤 항목을 주는지 확인 필요 |
| 드라이브 리플레이 | 주행 중 차량 상태를 타임라인으로 다시 보고, 운전자별로 운행 기록을 모음 | 가족 공유 차량 관리에 활용 | 운전자 추정은 신원 인증이 될 수 없음, 공동 이용자 동의 문제 |
| 다음엔 | 방문 후 남긴 메모를 기억했다가, 같은 목적지를 설정하면 이전 경험을 보여줌 | 메모를 다음 이동 준비로 연결 | 별도 AI API 사용 조건, 목적지 이벤트가 에뮬레이터에서 동작하는지 확인 필요 |
| 차근차근 | 처음 타는 차의 기능을 안내하고, 실제로 조작했는지 차량 데이터로 확인 | 시연하기 쉽고 대상(신차·렌터카)이 분명 | 차에 익숙해지면 사용 빈도가 줄어듦, 차종별 콘텐츠 필요 |
| 온도취향 | 공조·시트 상태와 사용자 평가를 함께 기록해, 비슷한 상황에서 편했던 설정을 알려줌 | 반복 사용 이유, 자동 제어 없이 구현 가능 | 기본 AUTO 공조보다 나은 점 확인 필요, 기록이 적으면 추천이 어려움 |

- 그 밖에 나온 방향: 미래 지향성(전기차·자율주행), 기존 휘발유 차 대상, 전기차 충전 연결 실패 알림
- 평가 기준과 최종 비교는 [`01_ideas/comparison.md`](../01_ideas/comparison.md) 참고
