# EcoFit 기획 요약

> 제출 기획서(접수양식 02 앱 소개)의 핵심 내용을 저장소용으로 요약한 문서입니다. 그림은 [figures/](figures/)에 있습니다.

## 1. 한 줄 소개

**"같은 길을 달려도, 쓰는 전기는 다르니까."**
EcoFit은 출발 전 배터리 여유 확인부터 주행 후 회생 제동 추정 금액까지, 전기차의 전력 관리를 돕는 Pleos Connect 앱입니다.

## 2. 기획 배경

| 구분 | 내용 |
|---|---|
| 핵심 문제 | 전기차 운전자는 매 주행마다 목적지까지 배터리가 충분한지, 이번 주행에 비용이 얼마나 들었는지 직접 판단해야 함 |
| 시장 | 국내 전기차 누적 등록 109만 5천 대(2026년 6월 말, 국토교통부 자동차 등록 현황 인용 기사) |
| 구매 장벽 | 전기차 구매를 망설이는 이유: 충전 인프라 부족 45.3%, 충전 시간 32.8%, 주행거리 불안 29.3% (차봇모빌리티 450명 조사, 헤럴드경제 2026.2.9.) |
| 기존 방식의 한계 | 계기판은 전비·배터리 숫자만 보여주고, 회생 제동의 가치를 비용이나 거리로 보여주지 않음 |
| 가상 고객 검증 | BizForge(NVIDIA Nemotron 합성 페르소나) 가상 고객 100명 설문으로 원화 환산·도착 후 리포트 수요 확인 |

## 3. 주요 기능과 차량 특화 요소

| 단계 | 화면 | 제공 정보 |
|---|---|---|
| 출발 전 | 브리핑 | 도착 후 남는 거리, 30km 미만 경고·충전소 연결, 열선(약 8~10km)·에코 모드 제안, 경로 예상 회생 금액 |
| 주행 중 | 주행 화면 | 실시간 되찾은 전기요금(추정), "되찾는 중" 배지, "+7원" 팝업, 목적지까지 남은 거리 |
| 주행 후 | 리포트 | 되찾은 에너지·금액, 에코 점수, 승차감 점수, 급제동 코칭, 지난 주행 그래프 |
| 주간 | 홈 | 최근 7일 누적, 1년 환산액(× 52)을 생활 단위(치킨·국밥·커피·삼각김밥)로 표시 |

- **기어 연동:** D/R → 주행 중 화면, P → 리포트 자동 전환
- **차량 데이터:** Pleos Vehicle SDK(배터리·남은 주행거리·브레이크·주행 모드·공조·열선), AAOS CarPropertyManager(기어·차속·외기 온도), NaviHelper(목적지 거리·충전소 화면), TextToSpeech(온디바이스 음성)
- **음성 안내:** 주행 중에는 급제동·배터리 20% 미만만 안내하고 금액·칭찬은 화면으로만 표시. 급제동 안내는 15초 간격
- **주행 중 조작 최소화:** 권한 요청은 기어 P에서만, 큰 숫자·타일 중심 화면, 앱 문구는 "페달을 떼면 전기가 돌아온다"는 쉬운 말로 통일
- **데모 주행 모드:** 실차 없이 약 45초 가상 주행(목적지: 현대자동차 본사 12km). "데모 · 가상 데이터" 배지, 실행마다 ±15% 변동, 끝나면 실제 데이터로 자동 복귀

## 4. 주요 사용 시나리오

평일 출퇴근 + 주말 가족 장거리 이동 운전자가 토요일 오전 출발 전 배터리 여유를 확인하고, 주행 중에는 조작 없이 필요한 안내만 받으며, 도착 후 비용과 운전 습관을 확인해 다음 주행에 반영합니다.

| 시점 | 운전자가 얻는 것 |
|---|---|
| 출발 전 | 충전 여부를 미리 판단 |
| 주행 중 | 조작 없이 필요한 안내만 받음 |
| 도착 후 | 비용과 운전 습관을 확인하고 다음 주행에 반영 |

## 5. 개발 계획 (핵심 계산 기준)

| 항목 | 계산 방식 |
|---|---|
| 회생 에너지 추정 | (운동에너지 감소량 − 구름·공기 저항 손실) × 회생 효율 65%, 최대 회생 출력 100kW (차량 무게 2,050kg, 아이오닉 5 기준 근사) |
| 금액 환산 | 1kWh = 350원 (가정용 전기요금 기준, 되찾은 전기의 요금 환산액) |
| 급제동 / 급가속 | 감속 4.0m/s² 이상 1초 유지(3초에 1회) / 가속 3.0m/s² 이상 |
| 에코 점수 | 100 − 급제동 × 6 − 급가속 × 3 ± 전비 보너스(최대 ±10) |
| 급제동 없었다면 | 급제동 1회당 약 20Wh 손실 × 전비 |
| 1년 환산 | 최근 7일 환산액 × 52 |

- 서버 없이 주행 기록은 차량 내부 Room DB에만 저장, 위치 정보 수집 없음, 차량 제어 SDK 미사용
- 에뮬레이터 한계: 배터리가 닳지 않아 전비·소모량 미표시, 주행거리계 0 (실차에서는 정상 동작)

## 6. 기대효과 및 발전 가능성

- **사용자 효과:** 출발 전 충전 판단 부담 감소, 주행 결과를 비용과 점수로 확인, 운전 습관을 돌아볼 기준 제공
- **플랫폼 효과:** 차량 조회·내비게이션·음성 SDK를 한 앱에서 결합한 Pleos Connect 활용 사례
- **시장:** 2026년 상반기 국내 전기차 판매 +113.6%, 신차 중 비중 23.3% (KAMA) · 2025년 세계 전기차 판매 2,000만 대 이상, 신차의 25% (IEA) · 2030년까지 Pleos Connect 약 2,000만 대 탑재 계획 (현대자동차그룹)
- **확대 계획:** 1단계 실차 정확도 검증 → 2단계 주간·월간 리포트 → 3단계 차량 제어·음성 명령(승인 후) → 4단계 하이브리드·해외 적용
- **선점 효과:** Pleos Connect는 아직 EV 차종에 적용 전이지만, 현대자동차그룹은 2030년까지 약 2,000만 대 탑재 계획을 밝혔습니다. EcoFit은 Pleos Vehicle·NaviHelper·TextToSpeech SDK 기반으로 이미 개발·검증을 마쳐, 실제 Pleos EV가 출시되는 시점에 추가 개발 기간 없이 바로 탑재·상용화할 수 있는 상태입니다.

> 금액·에너지·추가 주행거리 환산값은 계산 모델에 따른 추정치이며, 실제 충전비 절감 효과는 실차 평가로 확인합니다.
