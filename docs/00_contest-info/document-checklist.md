# 서류 제출 필수 확인사항

> 출처: 공모전 접수양식 (동의서 1020 ver.)
> 공모전 전체 제출 조건은 [제출 조건 체크리스트](submission-checklist.md)를 참고하세요.

## 1. 제출 안내

- [ ] 회원가입 없이 작성한 신청서와 제출자료를 이메일로 제출
- [ ] 접수 이메일: appdevchallenge@hyundai-partners.com
- [ ] 접수기간: 2026.10.21(수) ~ 2026.11.15(일) 23:59
- [ ] 메일 제목: `[차량용 앱 개발 공모전] 팀명(개인은 성명)_대표자명`
- [ ] 접수양식이 곧 기획서. 작성·서명한 접수양식을 이메일로 제출
- [ ] 시연 영상·GitHub 저장소·APK는 선택 제출(가산점 부여)
- [ ] 숏폼 링크는 선택 제출(가산점 없음)
- [ ] 수정 시 같은 발신자 이메일로 최종 수정본 재제출 (마감 전 최종 발송본으로 심사)

## 2. 02 앱 프로젝트 소개 작성 시 주의

- [ ] 대표자·구성원의 성명, 연락처, 이메일, 소속은 기재하지 않음 (01 참가신청서에만 기재)
- [ ] Word에서는 박스 안을 클릭해 입력 (내용이 길면 작성란이 늘어남)
- [ ] 소개 자료 분량 제한 없음
- [ ] 공유 링크와 첨부자료에도 개인정보·계정정보·개발자 실명이 노출되지 않도록 확인

## 3. 04 동의 확인 및 서명

- [ ] 팀 참가 시 대표자와 모든 팀원란을 각각 작성
- [ ] 대표 참가자는 제출 이메일의 참조(CC)에 모든 팀원 이메일 주소 포함
- [ ] 팀원 각자의 동의 여부와 본인 서명 필요 (CC 수신만으로 동의 대체 불가)
- [ ] CC 이메일 주소는 팀의 다른 수신자에게도 표시되므로 제출 전 팀원에게 안내
