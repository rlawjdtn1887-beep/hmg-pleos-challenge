## 공모전 개요

- 공모전명: 현대자동차그룹 차량용 앱 개발 공모전 (Code your App into Pleos App Market)
- 주최: 현대자동차그룹
- 주관: (공식 페이지에 별도 표기 없음)
- 공식 페이지: https://appdevchallenge.auto-hmg.io/
- 참가 자격: 대학(원)생, 일반인, 스타트업 — 개인 또는 팀(최대 5인) 참가 가능
- 팀 구성 조건: 개인 또는 최대 5인 팀. 대표자와 팀원 전원이 개인정보 수집·이용 동의서에 개별 서명하고, 대표자가 팀원 전원을 CC하여 접수 이메일로 제출
- 시상 부문: 대학생 부문 / 일반(스타트업 포함) 부문
- 시상 내역: 총상금 5,100만원, 10개 팀 선정 (아래 "시상 내역" 표 참고)

## 심사 기준

1차 서류심사는 아래 4개 필수 항목과 가산점 항목으로 구성됩니다. 세부 배점은 공식 페이지에
공개되지 않았습니다. 2차 PT 심사 기준은 추후 별도 공지 예정입니다.

| 항목 | 배점 | 설명 |
|------|------|------|
| 차량특화성 (필수) | 비공개 | 모바일 대비 차량 환경만의 독자적 가치, 주행·정차 맥락 및 차량 기능과의 유기적 결합 |
| 창의성 (필수) | 비공개 | 독창적·혁신적인 아이디어인지, 운전자/동승자의 Pain Point와 해결 방식이 명확한지 |
| 기술 활용성 (필수) | 비공개 | Pleos Playground SDK/API를 앱 핵심 기능·경험에 적절히 활용했는지 |
| 사업성 (필수) | 비공개 | 타깃 고객 명확성, MAU·Retention 등 사용자 확보·확대 가능성 |
| 가산점 (선택 제출) | - | 시연 영상, GitHub 저장소(소스 코드+APK) 제출 시 단계별 가산점 부여 |

## 시상 내역

총상금 **5,100만원**, **10개 팀** 선정.

| 상격 | 상금 | 팀 수 | 부문 |
|------|------|------|------|
| 대상 | 1,000만원 | 2팀 | 대학생 1팀, 일반 1팀 |
| 최우수상 | 600만원 | 2팀 | 대학생 1팀, 일반 1팀 |
| 우수상 | 400만원 | 4팀 | 대학생 2팀, 일반 2팀 |
| 아이디어 특별상 | 150만원 | 2팀 | 두 부문 통합 선정 |
| 숏폼 챌린지 어워드 | 50만원 | 1팀 | 본상 총상금과 별도 시상 |

- 최종 선정 10개 팀은 Pleos App Market 탑재를 지원받으나, 별도 검증·심사를 거치며 최종 입점/배포는
  보장되지 않습니다.
- 최종 선정 팀은 현장 시연용 최종 구동 APK를 필수 제출해야 하며, 전시 영상 제작과 현장 시연에
  협조합니다.

## 요강 요약 메모

- 개발 환경: Android API 28 이상, Gradle 8.0 이상, Java 또는 Kotlin
- 사용 가능 SDK: Vehicle, NaviHelper, TextToSpeech, SpeechToText, FusedLocation (제공 상태·조건은
  Pleos Playground SDK 문서에서 별도 확인)
- 제출 방식: 이메일(appdevchallenge@hyundai-partners.com) 단일 접수. 접수양식(기획서)만으로 지원
  가능하지만, 2차 PT 심사 대상 팀은 PT 전까지 실제 동작하는 앱을 완성해야 함
- 1차 접수 시 제출한 개발 산출물(시연 영상/GitHub/APK)은 2차 PT 심사 전까지 자유롭게 고도화 가능
- 제출물 세부 양식(파일 형식/분량 제한)은 접수양식 다운로드 시 확인 필요 — 공식 페이지 본문에는
  명시되지 않음
