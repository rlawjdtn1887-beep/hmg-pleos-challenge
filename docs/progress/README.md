# 주간 진행 보고

팀원 각자 매주 한 일을 기록합니다. 공모전 제출용 README의 "팀원별 기여" 표는 이 기록을 바탕으로 작성합니다.

## 작성 방법

1. [`_template.md`](_template.md)를 복사해서 새 파일을 만듭니다.
   - 파일명: `<주차>-<GitHub아이디>.md` (예: `week01-rlawjdtn1887-beep.md`)
2. 이번 주 한 일, 관련 이슈·PR 링크, 다음 주 계획을 적습니다.
3. 다른 작업과 마찬가지로 브랜치를 만들어 PR로 올립니다. (라벨: `docs`)
