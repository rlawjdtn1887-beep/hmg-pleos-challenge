# 아이디어 후보 비교표

> 10/26 아이디어 공유 후 팀 논의로 기준을 정하고 최종 아이템을 선정했습니다.

## 평가 기준

| 기준 | 설명 | 확인 방법 |
|------|------|-----------|
| 개발 가능성 | 공개된 Pleos SDK 범위(차량 상태 조회, 내비 연동, 음성 안내) 안에서 만들 수 있는가 | Pleos Connect 에뮬레이터에서 SDK 동작 확인 |
| 고객 니즈 | 전기차 운전자가 실제로 겪는 문제인가 | BizForge 가상 고객 100명 설문·의견 종합 |
| 차량 특화 | 차 안에서, 주행 단계에 맞춰 써야 의미가 있는가 | 기어·차속 연동, 주행 중 조작 최소화 가능 여부 |

## 비교

| 후보 | 개발 가능성 | 고객 니즈 | 차량 특화 | 비고 |
|------|-------------|-----------|-----------|------|
| 01 REGEN | 차량 상태 조회·내비 연동만으로 구현 가능 | 원화 환산·도착 후 리포트 수요 확인 | 기어 연동 자동 화면 전환, 주행 중 음성 최소화 | 최종 선정 |

## 결론

**EcoFit (에코핏)** 으로 최종 선정했습니다. 아이디어 01 REGEN을 발전시킨 회생 제동 코치 앱입니다.

- 차량 제어 없이 조회 SDK만으로 핵심 기능(회생량 추정, 출발 전 배터리 여유, 주행 리포트)을 만들 수 있었습니다.
- 가속 페달을 뗄 때 돌아오는 전기를 전기요금으로 보여주는 방식은 계기판이 주지 않는 정보라 차별점이 분명했습니다.
- 출발 전·주행 중·주행 후로 나뉘는 흐름이 기어 상태와 바로 연결돼 차량용 앱의 특성을 살릴 수 있었습니다.

자세한 기획 내용은 제출 기획서와 [docs/05_submission/figures/](../05_submission/figures/)를 참고하세요.
