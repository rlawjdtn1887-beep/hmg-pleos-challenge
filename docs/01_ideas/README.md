# 아이디어 후보

## 작성 방법

1. [`_template.md`](_template.md)를 복사해서 새 파일을 만듭니다.
   - 파일명: `idea-<번호>-<짧은이름>.md` (예: `idea-01-sample.md`)
2. 항목을 채운 뒤 PR로 올립니다. (라벨: `idea`)
3. 후보가 모이면 [`comparison.md`](comparison.md)에서 비교합니다.
