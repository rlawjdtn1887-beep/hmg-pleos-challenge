| 파일 | 화면 |
|---|---|
| 01_intro.png | 첫 실행 소개 화면 ("가속 페달을 떼면 돈이 쌓여요", 시작하기 / 데모 보기) |
| 02_tour.png | 안내 투어 1/5 (대상 타일만 밝게 남기고 말풍선으로 설명) |
| 03_home_empty.png | 홈 — 기록이 없을 때 |
| 04_briefing_no_dest.png | 출발 전 — 내비 목적지가 없을 때 |
| 05_briefing_dest.png | 출발 전 — 목적지 있을 때 (데모: 현대자동차 본사 12km, 도착 후 276km, 열선 제안) |
